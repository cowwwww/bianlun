🔧 创建所有集合

说明

⚠️ 重要提示：

PocketBase 的集合只能通过管理界面创建，不能通过 JavaScript API 创建。

请按照下面的步骤在管理界面中手动创建集合。

第一步：打开管理界面

或访问: http://127.0.0.1:8090/_/

第二步：创建 tournaments 集合

  1. 点击左侧 "Collections"
  2. 点击 "+ New collection"
  3. Name: tournaments
  4. Type: Base collection
  5. 点击 "Create"
  6. 添加以下字段 (点击 "+ New field"):
name               - Text (Required ✅)
title              - Text
description        - Text
startDate          - Text
endDate            - Text
registrationDeadline - Text
location           - Text
type               - Text
status             - Text
price              - Number
organizer          - Text
contact            - Text
category           - Text

API Rules (重要!):

  • List/Search: 留空 (允许所有人查看)
  • View: 留空
  • Create: @request.auth.id != ""
  • Update: @request.auth.id != ""
  • Delete: @request.auth.id != ""

第三步：创建 topics 集合

  1. 点击 "+ New collection"
  2. Name: topics
  3. Type: Base collection
  4. 点击 "Create"
  5. 添加以下字段:
text               - Text (Required ✅)
explanation        - Text
area               - Text
language           - Text
tournament         - Text

API Rules:

  • List/Search: 留空
  • View: 留空
  • Create: @request.auth.id != ""
  • Update: @request.auth.id != ""
  • Delete: @request.auth.id != ""

第四步：创建 timer_projects 集合

  1. 点击 "+ New collection"
  2. Name: timer_projects
  3. Type: Base collection
  4. 点击 "Create"
  5. 添加以下字段:
name               - Text (Required ✅)
description        - Text
type               - Text (Required ✅)
duration           - Number
createdBy          - Text (Required ✅)

API Rules:

  • List/Search: 留空
  • View: 留空
  • Create: @request.auth.id != ""
  • Update: @request.auth.id != ""
  • Delete: @request.auth.id != ""
