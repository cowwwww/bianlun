🚀 PocketBase 快速设置工具

⚠️ 重要提示：确保 PocketBase 正在运行：http://127.0.0.1:8090

📋 设置步骤

步骤 1: 打开 PocketBase Admin

首先，打开 PocketBase 管理面板：

如果是第一次使用，您需要创建管理员账号

步骤 2: 创建 Collections（手动操作）

在 PocketBase Admin 面板中，按照以下说明创建集合：

📦 Collection 1: tournaments

  1. 点击 "New collection" 或 "新建集合"
  2. Collection name: tournaments
  3. Type: Base collection
  4. 添加以下字段：
name            - Text (required)
title           - Text
description     - Text
startDate       - Text
endDate         - Text
registrationDeadline - Text
date            - Text
location        - Text
type            - Text
status          - Text
price           - Number
teamsize        - Text
organizer       - Text
contact         - Text
category        - Text
image           - Text
totalTeams      - Number
playersPerTeam  - Number
participationRequirements - Text
registrationLink - Text
ruleBookLink    - Text
award           - Text

📦 Collection 2: topics

text            - Text (required)
explanation     - Text
area            - Text
language        - Text
tournament      - Text
ratings         - JSON
averageRating   - Number

📦 Collection 3: timer_projects

name            - Text (required)
description     - Text
type            - Text (required)
duration        - Number
createdBy       - Text (required)

步骤 3: 设置 API 权限

为每个集合设置 API Rules（在 API Rules 标签）：

List/Search Rule:  留空（公开访问）或 @request.auth.id != ""
View Rule:         留空（公开访问）
Create Rule:       @request.auth.id != ""
Update Rule:       @request.auth.id != ""
Delete Rule:       @request.auth.id != ""

💡 提示：完成以上步骤后，刷新您的应用页面，错误应该就会消失了！

🔍 验证安装

📝 如果仍然出错

常见问题排查：

  1. PocketBase 没有运行 - 确保在终端运行 ./pocketbase serve
  2. 端口错误 - 确认 PocketBase 运行在 8090 端口
  3. 集合名称拼写 - 集合名必须完全匹配（小写）
  4. 权限设置 - 确保 API Rules 设置正确
